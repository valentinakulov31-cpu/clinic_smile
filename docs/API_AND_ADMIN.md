# Полное описание: админка и API

Backend сайта стоматологии «Улыбнись». Структура страниц — по новым макетам Figma (редизайн), функционал — с учётом старого сайта https://ulybnis24.ru/.

- Админка: `http://127.0.0.1:8015/admin/`
- Swagger UI: `http://127.0.0.1:8015/api/docs/`
- ReDoc: `http://127.0.0.1:8015/api/redoc/`

Все контентные списки отдаются **без пагинации** (массив целиком). Везде, где у записи есть флаг «Активно», API отдаёт только активные записи; порядок задаётся полем «Сортировка».

## 1. Разделы админки и какие страницы сайта они наполняют

### Общее для всего сайта (шапка, футер)

| Раздел админки | Что заполняется | Где видно на сайте |
|---|---|---|
| **Настройки сайта** (одна запись) | Название сайта, логотип, копирайт футера, дисклеймер «Имеются противопоказания…», заголовок и подзаголовок CTA-блока записи («…план лечения за 1000 ₽»), ссылка на полную версию прайса (Google Sheets) | Шапка, футер, повторяющийся блок записи на всех страницах, страница цен |
| **Соцсети** | Название, ссылка, иконка | Футер, страницы «Пациентам» и «Контакты» |
| **Контакты** (одна запись) | Адрес, телефоны (по одному на строку), email, режим работы, координаты, ссылка на карту + SEO | Шапка (телефоны), футер, страница «Контакты» |
| **Реквизиты** (одна запись) | Наименование, ИНН, КПП, ОГРН, банк, счета, БИК, юр. адрес, PDF-файл с реквизитами | Страница «Контакты» |
| **Филиалы** | Задел на будущее (несколько адресов). Сейчас можно не заполнять — источник контактов сайта — раздел «Контакты» | — |

### Главная страница

| Раздел админки | Что заполняется | Блок на главной |
|---|---|---|
| **Главная страница** (одна запись) | Вкладка «Герой»: заголовок, подзаголовок, тексты двух кнопок («Записаться» / «Наши услуги»), картинка. Вкладка «О клинике»: заголовок, текст (короткий, для главной), картинка. Вкладка SEO | Hero-баннер, блок «О клинике» |
| **Категории услуг** | Название, подпись (описание), фото карточки | 3 карточки направлений после hero (Эстетическая стоматология / Лечение зубов / Имплантация и протезирование) |
| **Преимущества** | Текст, заголовок (опц.), иконка | Резерв со старого сайта (в новом макете блока нет, API остаётся) |
| **Специальные предложения** | см. ниже | Блок «Акции» |
| **Специалисты** | см. ниже | Блок «Сотрудники» |
| **Отзывы** | Автор, текст, рейтинг 1–5, источник, ссылка, дата | Блок «Отзывы» (и страница «О клинике») |

### Услуги (страница /services и детальные страницы услуг)

| Раздел админки | Что заполняется |
|---|---|
| **Категории услуг** | Название, подпись, иконка, фото карточки для главной + SEO |
| **Услуги** | Название, категория, краткое/полное описание, иконка (для сетки страницы «Услуги»), картинка карточки, логотип, 3 бейджа героя, филиалы + SEO. Инлайны: галерея изображений и блоки страницы |
| **Блоки страницы услуги** | Конструктор детальной страницы услуги. Тип «Текстовый блок»: заголовок + Markdown-текст + картинка. Тип «Карточки»: карточки с заголовком/подзаголовком/описанием/ценой-текстом/картинкой (напр. «Виды имплантов», «Кому подойдёт?»). Тип «Этапы»: те же карточки, фронт рендерит их нумерованными («Этапы работы», номер = порядок сортировки) |

### Цены (страница /prices)

| Раздел админки | Что заполняется |
|---|---|

### Акции (страница /promotion)

| Раздел админки | Что заполняется |
|---|---|
| **Специальные предложения** | Название, краткое/полное описание, картинка, цена, старая цена, «цена от», даты действия, связь с услугой/филиалами + SEO |
| **Статичные страницы** → `offers` | Заголовок и SEO списка акций |

### Пациентам (страница /patients)

| Раздел админки | Что заполняется |
|---|---|
| **Страница пациентам** (одна запись) | Заголовок, текст (условия оплаты и пр.), картинка, выбор спецпредложений для показа + SEO |
| **Способы оплаты** | Название (Наличные, По карте, Рассрочка), иконка, описание |

### О клинике (страница /about)

| Раздел админки | Что заполняется |
|---|---|
| **Страница о клинике** (одна запись) | Заголовок, текст (история клиники), главное изображение + SEO. Инлайн: галерея |
| **Галерея** | Фото интерьера с подписями (можно привязать к странице «О клинике» или вести общую) |

### Документы, вакансии, политика

| Раздел админки | Что заполняется |
|---|---|
| **Категории документов** | Название группы (например, «Лицензии») |
| **Документы** | Название, описание, файл, дата публикации, категория |
| **Вакансии** | Название, краткое описание, картинка, обязанности, требования, условия, полный текст + SEO |
| **Статичные страницы** → `policy` | Политика конфиденциальности: заголовок + Markdown-текст |

### Статичные страницы — полный список ключей

Одна запись на страницу; заголовок, подзаголовок, текст (Markdown) и SEO:

`services` (список услуг), `prices` (цены), `doctors` (список врачей), `offers` (акции), `reviews` (отзывы), `documents` (документы), `vacancies` (вакансии), `policy` (политика конфиденциальности).

### Заявки (приложение appointments)

| Раздел админки | Что там |
|---|---|
| **Заявки** | Входящие заявки с форм сайта: тип (консультация / запись / обратный звонок / отклик на вакансию), имя, телефон, email, комментарий, связанные услуга/врач/филиал/вакансия, файл (резюме), источник формы, статус (Новая → В работе → Обработана / Отменена) |

### Автоматика админки

- `slug`, SEO title/description, Open Graph заполняются автоматически из названия/описания, если оставить пустыми. Заполненное вручную не перезаписывается.
- Записи-синглтоны (Главная, О клинике, Пациентам, Контакты, Реквизиты, Настройки сайта) — админка не даст создать вторую запись.
- У SEO-сущностей поля вынесены в отдельную вкладку «SEO».
- Загрузка файлов ограничена по размеру (20 МБ) и форматам (изображения: jpg/png/webp; документы: + pdf/doc/xls).

## 2. Полное описание API

Базовый префикс: `/api/`. Все GET-endpoints публичные, без авторизации.

### Общие данные сайта

| Endpoint | Что возвращает | Для чего фронту |
|---|---|---|
| `GET /api/settings/` | `site_name`, `logo`, `copyright_text`, `disclaimer`, `cta_title`, `cta_subtitle`, `price_full_url`, вложенный массив `social_links` | Шапка, футер, CTA-блок — запросить один раз на приложение |
| `GET /api/contacts/` | `address`, `phones[]`, `email`, `work_hours`, `latitude`, `longitude`, `map_url`, SEO + вложенные `requisites` (все поля реквизитов и `file` — PDF) | Шапка, футер, страница контактов |
| `GET /api/social-links/` | `title`, `url`, `icon` | Если соцсети нужны отдельно от настроек |
| `GET /api/branches/` | Филиалы: название, адрес, телефоны, email, режим, координаты | На будущее (мультифилиальность) |

### Главная страница

| Endpoint | Что возвращает |
|---|---|
| `GET /api/home/` | `hero_title`, `hero_subtitle`, `hero_button_text`, `hero_secondary_button_text`, `hero_image`, `about_title`, `about_text`, `about_image`, вложенные `advantages[]` (title, text, icon), SEO |
| `GET /api/advantages/` | Преимущества (резерв со старого сайта) |

Остальные блоки главной: карточки направлений — `/api/service-categories/` (`name`, `description`, `image`), специалисты — `/api/specialists/`, акции — `/api/offers/`, отзывы — `/api/reviews/`.

### Услуги

| Endpoint | Параметры | Что возвращает |
|---|---|---|
| `GET /api/service-categories/` | — | Категории: `name`, `slug`, `description` (подпись), `icon`, `image` (фото карточки на главной), SEO |
| `GET /api/services/` | `?branch=<id>`, `?category=<slug>` | Карточки: `name`, `slug`, вложенная `category`, `short_description`, `icon` (для сетки услуг), `card_image`, SEO |
| `GET /api/services/{slug}/` | — | Всё для детальной страницы: `preview_logo`, `card_image`, `name`, `short_description`, `description`, `hero_badges[]` (3 бейджа), `page_blocks[]`, `images[]` (галерея), `branches[]`, SEO + OG |

Структура `page_blocks[]`: `block_type` (`text` \| `cards` \| `steps`), `title`, `description` (Markdown), `image`, `cards[]`. У карточки: `title`, `subtitle`, `description`, `price_text`, `image`. `cards` фронт рендерит каруселью/сеткой, `steps` — нумерованными карточками «Этапы работы» (номер = позиция).

### Цены

| Endpoint | Параметры | Что возвращает |
|---|---|---|
| `GET /api/prices/` | `?branch=<id>` | Категории прайса с вложенными `items[]`: `title`, `price`, `is_from_price`, `comment`, связи `service`/`branch`. Категории без активных позиций не возвращаются |

Ссылка на полную версию прайса — в `/api/settings/` (`price_full_url`), заголовок/SEO страницы — `/api/pages/prices/`.

### Акции

| Endpoint | Параметры | Что возвращает |
|---|---|---|
| `GET /api/offers/` | `?branch=<id>` | `title`, `slug`, описания, `image`, `price`, `old_price`, `is_from_price`, `starts_at`, `ends_at`, связи, SEO + OG |

### Специалисты

| Endpoint | Параметры | Что возвращает |
|---|---|---|
| `GET /api/specialists/` | `?branch=<id>` | Карточки: вложенная `category` (группа), `full_name`, `slug`, `photo`, `position`, `specializations`, `short_description`, `experience` |
| `GET /api/specialist-categories/` | — | Группы («Врачи», «Младший персонал», «Администрация») с вложенными активными `specialists[]` — для страницы «Специалисты» с секциями; пустые группы не возвращаются |
| `GET /api/specialists/{slug}/` | — | + `description`, `education`, `services[]`, `branches[]`, `documents[]` (сертификаты: title, file), SEO + OG |

### Страницы

| Endpoint | Что возвращает |
|---|---|
| `GET /api/patients-page/` | `title`, `text`, `image`, выбранные `offers[]`, все активные `payment_methods[]` (title, icon, description), SEO |
| `GET /api/about/` | `title`, `text`, `image`, `gallery[]` (image, caption), SEO |
| `GET /api/gallery/` | Вся галерея отдельно |
| `GET /api/pages/` | Все статичные страницы разом |
| `GET /api/pages/{key}/` | Одна страница по ключу (`services`, `prices`, `doctors`, `offers`, `reviews`, `documents`, `vacancies`, `policy`): `key`, `title`, `subtitle`, `text` (Markdown), SEO |

### Вакансии

| Endpoint | Что возвращает |
|---|---|
| `GET /api/vacancies/` | Карточки: `title`, `slug`, `short_description`, `image` |
| `GET /api/vacancies/{slug}/` | + `responsibilities`, `requirements`, `conditions`, `description`, SEO |

### Документы и отзывы

| Endpoint | Что возвращает |
|---|---|
| `GET /api/documents/` | Плоский список: `title`, `description`, `file`, `published_at`, вложенная `category` |
| `GET /api/document-categories/` | Категории с вложенными активными `documents[]` — для страницы документов с группировкой |
| `GET /api/reviews/` | `author_name`, `text`, `rating` (1–5), `source`, `source_url`, `reviewed_at` |

### Формы заявок (POST)

| Endpoint | Тип заявки | Особенности |
|---|---|---|
| `POST /api/requests/consultation/` | Бесплатная консультация | |
| `POST /api/requests/appointment/` | Запись на приём | Можно передать `service`, `specialist`, `branch` (id) |
| `POST /api/requests/callback/` | Обратный звонок | |
| `POST /api/requests/vacancy/` | Отклик на вакансию | `vacancy` (id) обязателен, можно приложить файл `attachment` (резюме) |

Тело запроса:

```json
{
  "name": "Иван",
  "phone": "+7 999 000-00-00",
  "email": "ivan@example.com",
  "comment": "Хочу записаться",
  "source": "hero-form",
  "website": ""
}
```

- `name` и `phone` обязательны, остальное опционально.
- `website` — honeypot: скрытое поле, отправлять пустым; заполненное значение = заявка отклоняется.
- `source` — свободная метка формы («hero-form», «footer»…), видна менеджеру в админке.
- Ответ `201` с созданной заявкой; заявка появляется в админке со статусом «Новая», менеджеру уходит email (если настроен SMTP).
